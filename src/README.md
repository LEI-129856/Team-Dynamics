# Mensagem Parser

Estrutura inicial para processar mensagens de trabalho e gerar um ficheiro JSON.

## Estrutura

- backend/: lógica de processamento
- frontend/: interface futura
- middleware/: camada de integração futura
- data/: mensagens de exemplo e resultado exportado

## Como usar

```bash
npm start
```

O resultado será guardado em data/output/result.json.
